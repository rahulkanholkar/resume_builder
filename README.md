# Folio Resume Builder

A Ruby on Rails resume builder with a template gallery, account-based resume workspace, live editor, exports, ATS checks, public resume links, and an application tracker.

## Run locally

Requirements: Ruby 3.4 and SQLite.

```sh
bundle install
bin/rails db:prepare
bin/rails server
```

Visit `http://localhost:3000`. Create an email and password account to save resumes. Run the test suite with `bin/rails test`.

## Included features

- 23 visually distinct resume templates across professional, modern, creative, executive, industry-specific, and fresh graduate styles, including three photo-led split layouts based on the supplied references.
- Email and password accounts; multiple resumes; copy, rename, archive, restore, and version history.
- Add, hide, remove, rename, and drag to reorder standard or custom sections. Inline rich text, character counts, live preview, and autosave are included.
- Download PDF, DOCX, and TXT files; print-friendly layouts; public resume links with view, download, and link-copy counts.
- Local ATS checks for common keywords, missing sections, basic formatting, and readability. Paste a job description for keyword match and missing-skill suggestions.
- Local writing prompts for summaries, experience bullets, skills, cover letters, interview practice, and job tailoring. These are deterministic starter suggestions, not generated by an AI model.
- Application tracker for saved, applied, interview, rejected, and offered roles.
- Peer comments on public resumes and programming, marketing, sales, and communication self-assessments. Passing self-assessments earn clearly labeled self-assessment badges.

## Integration limits

This local build does not connect to Google, LinkedIn, or GitHub OAuth, external AI providers, LinkedIn/Indeed/Glassdoor/Naukri/Monster job APIs, or one-click application services. Those need provider credentials and integration work. Resume and user data currently use the configured Rails database; cloud backup and cross-deployment sync depend on production hosting and database setup. Public pages provide a shareable resume/portfolio view, but custom domains, QR generation, independent skill verification, expert-review workflows, and recruiter location/device analytics are not configured.
